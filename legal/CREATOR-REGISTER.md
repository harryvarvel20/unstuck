# ADHV — Creator Register

**Purpose:** one place recording who was issued which code, when they accepted
the terms, and where the evidence lives.

If the ASA or a customer ever queries a promotion, this is the document that
answers "who posted it, under what terms, and can you prove they agreed" in
under a minute. Without it, that is an afternoon of searching an inbox.

> ⚠️ **Do not record personal contact details, bank details or invoices here.**
> This file is in the git repository. Keep those in
> `ADHV/legal/Creators/` in cloud storage and reference them by folder name.

## Rules for this register

1. **A row exists before a code is issued.** Not after the post goes live.
2. **"Accepted" means written acceptance is in hand** — an email saying "I
   agree" — not that the terms were sent.
3. **Terms version matters.** If `AFFILIATE-TERMS.md` changes, creators
   remain on the version they accepted until they accept a new one. Record
   which.
4. **One code per creator.** Shared codes make it impossible to say who drove
   a signup, or whose content caused a problem.
5. **Deactivating a code does not end commission** already earned on existing
   customers — see `AFFILIATE-TERMS.md` §5.
